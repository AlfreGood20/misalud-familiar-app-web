# Aplicacion web gestor familiar medico

## Requesitos 
- Node.js v22+
- git 2.47+
- VS CODE

## Pasos para su instalacion
1. Clonar el repositorio
```bash
git clone https://github.com/AlfreGood20/web-gestor-familiar-medico.git
```

2. Entrar al proyecto
```bash
cd <nombre-carpeta>
```

3. Instalar dependecias
```powershell
npm install
```

4. Correr el servidor
```
npm run dev
```

> **IMPORTANTE:** Crea un `.env` en la raiz del proyecto y adentro de ese archivo agrega la url de la api, `VITE_API_URL = 'https://api-url...'` para que el sistema pueda ser usable.
