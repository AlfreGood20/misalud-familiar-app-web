## Reglas para la ia
- Sigue la estructuras de modularizacion del proyecto todo en su respectivas modularizacion por ejemplo si crear una pagina modulariza por componente en caso que se requiera.

- Esta web va consumir la api que le daremos, pero esta yo te indicare los endpoints que vayamos a consumir.

- El modulo `services` ahi es donde guardaras el consumo de la enpoint y llamalos como el nombre del feature que estamos trabajando.

- Usa los componente de tailwindcss y la libreria de daisyUI para la parte visual de la web, NO USES O CREE `CSS`.

- Al crear una pagina indicale en el `App.jsx` la ruta usando react router.

- Usa la liberia de touter de react para mensaje llamativos.

- Analiza que componentes tenemos y si es posible de reutilizar lo usaremos, siempr ey cuando yo este de acuerdo que lo usaremos pero si esta usalo.

- Sigue el diseño y colores que estamos trabajando no cambies el estilo de la web.
